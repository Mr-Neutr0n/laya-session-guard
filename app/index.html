03 / HOW TO READ THIS

What counts as fast?

The timing shown here measures model inference only, after each checkpoint loads. P50 is the median decision time; P95 shows slower decisions. These local measurements can vary when both models run at once; use the paired Kaggle run for a controlled latency comparison. This app reads an archived Stanford Wikispeedia graph from disk, so page fetch time is zero during a race. The article links open live Wikipedia only when you click them.
